# Eco Lux Sleek

Cinematic, luxury marketing + e-commerce site for a Sleek (Asian Paints) distributor serving South Gujarat (Surat, Bharuch, Navsari, Valsad, Vapi).

## Stack

Next.js 15 (App Router) · React 19 · TypeScript · Tailwind CSS v4 · shadcn/ui · GSAP · Framer Motion · Three.js / React Three Fiber · Lenis · React Hook Form + Zod

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
